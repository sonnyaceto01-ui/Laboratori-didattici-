# Strumenti didattici per laboratori di cybersecurity

Piccoli programmi Python pensati per essere usati in laboratori scolastici 
ed extrascolastici di sensibilizzazione alla sicurezza informatica, per 
mostrare in modo pratico e visivo concetti che altrimenti resterebbero 
astratti per studenti e pubblico non tecnico.

---

## 📁 Strumenti disponibili

### 🔐 Password Strength Checker
Permette agli studenti di inserire una password (finta, mai una vera!) e 
vedere subito quanto è "forte", con un punteggio e suggerimenti concreti 
su cosa aggiungere per migliorarla.

**Uso in laboratorio:** ottimo per far provare dal vivo diverse password 
e mostrare come piccole modifiche (aggiungere un numero, un simbolo, 
allungarla) cambino il punteggio — rende visibile un concetto altrimenti 
teorico.

**Come eseguirlo:**
```bash
python3 password_checker.py
```
